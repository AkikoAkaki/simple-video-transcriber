# Vocabulary Banlist & Direct Replacements

This reference lists words, phrases, and expressions overrepresented in LLM outputs ("AI-isms"). Avoid these in prose, articles, and documentation, and use the suggested direct replacements instead.

---

## 1. English Banned Words & Replacements

| Banned AI Word / Phrase | Why It Fails | Recommended Direct Replacement |
| :--- | :--- | :--- |
| **delve / delve into** | Overused AI verb for analysis. | *examine, inspect, study, analyze, look at, explore* (or drop entirely) |
| **tapestry** | Overused metaphor for complex systems. | *system, network, combination, mix, structure* |
| **testament to / stands as a testament** | Generic hyperbole. | *shows, proves, demonstrates, reflects* |
| **vibrant** | Vague, lazy positive adjective. | *active, busy, strong, distinct, clear* |
| **beacon / beacon of hope** | Cliché inspirational metaphor. | State the actual function or impact directly. |
| **foster** | Corporate filler verb for encouraging things. | *build, support, create, develop, encourage* |
| **intricate / multifaceted** | Overused filler for complexity. | Describe the specific parts or use *complex, detailed*. |
| **paramount / pivotal / crucial** | Over-dramatized importance. | *key, main, important, critical* |
| **landscape (e.g., "AI landscape")** | Generic domain metaphor. | *field, industry, domain, market, sector* |
| **game-changer / paradigm shift** | Inflated buzzwords. | Describe the exact difference or improvement. |
| **harness / leverage** | Overused verbs for using tools/data. | *use, apply, employ, run, deploy* |
| **underscore / highlight** | Repetitive emphasis markers. | *show, emphasize, note, point out* |
| **interplay / nexus** | Pseudo-intellectual linkers. | *relationship, link, connection, interaction* |

## 2. Chinese Banned Words & Replacements (中文黑名单与替换建议)

| 禁用 AI 词汇 / 套话 | 问题所在 | 推荐直接替代词 / 处理方式 |
| :--- | :--- | :--- |
| **深入探讨 / 深入剖析** | 机械化开头动词，缺乏实质内容。 | 直接说要讨论什么（如“分析…”、“查看…”），或删除该动词。 |
| **画卷 / 织锦** | 抽象空洞的比喻。 | *结构、体系、网络、框架* 或直接描述具体构成。 |
| **见证 / 完美的体现** | 夸张且无意义的修饰。 | *说明、表明、体现出* |
| **赋能 / 打通 / 重塑** | 互联网/公关黑话套路。 | *支持、连接、改进、优化、修改* |
| **值得注意的是 / 不可否认的是** | 无谓的防卫性客套垫字。 | 直接陈述事实，删掉这半句话。 |
| **总而言之 / 综上所述** | 强行在结尾加模板化总结。 | 删除总结段，或用具象结论代替。 |
| **闭环 / 矩阵 / 底层逻辑** | 非专业场景下的概念滥用。 | 使用具体业务或技术词汇（如“反馈机制”、“功能集”、“核心机制”）。 |
| **不可或缺 / 举足轻重** | 夸大重要性的套话。 | 说明具体的依附关系或影响。 |

## 3. Transitional & Meta-Filler Banned Expressions

Do not use the following transitions; they break the natural flow of thought:
- *In today's fast-paced digital world / 在当今快速发展的数字时代...*
- *It is important to remember that... / 必须记住的是...*
- *As mentioned earlier / 正如前文所述...*
- *Not only X, but also Y / 不仅 X，而且 Y...* (When used repetitively across paragraphs)
- *Ultimately, only time will tell / 归根结底，只有时间能给出答案...*
